はてなブログ→静的HTML(Python) 使い方ガイド

はてなブログのエクスポート（MT形式）を静的HTMLに変換するスクリプト hatena2static.py の使い方です。

できること

  • MT形式のエクスポートファイルから、記事ごとのHTML、トップページ（年別一覧）、カテゴリ別ページを生成します。
  • ブログカードを、はてなのサービスに依存しない静的なカードHTMLに置き換えます。
  • 同じブログの記事へのリンクを、ローカルの相対パスに書き換えます。
  • 標準ライブラリだけで動作します（Python 3.8以降）。--markdown を使うときだけ pip install markdown が必要です。

クイックスタート

  1. はてなブログの管理画面から、MT形式のエクスポートファイルをダウンロードします（設定 → 詳細設定 → エクスポート。メニュー名は変更されている場合があります）。
  2. hatena2static.py と同じフォルダにエクスポートファイルを置きます。
  3. 次のコマンドを実行します。
python3 hatena2static.py export.txt -o site --title "ブログ名"
  1. site/index.html をブラウザで開いて確認します。

よく使う例

# 自分のブログのURLを明示する（独自ドメインの場合など。複数指定可）
python3 hatena2static.py export.txt --blog-url https://example.hatenablog.com

# まずネットワークなしで動作確認（外部URLはリンクのみ）
python3 hatena2static.py export.txt --no-fetch

# 前回OGP取得に失敗したURLをやり直す
python3 hatena2static.py export.txt --retry-failed

# 本文がMarkdownの場合
pip install markdown
python3 hatena2static.py export.txt --markdown
自分のブログのURLは、本文中のURLと書き出す記事のBASENAMEを突き合わせて自動判定します。判定結果は実行時に表示されます。判定できない場合は警告が出るので、--blog-url を指定してください。

ブログカードの扱い

hatenablog-parts.com のiframeと、[URL:embed] の記法の両方を検出します。

元のURL処理
自分のブログの記事OGPは取得せず、ローカルへの相対パスに書き換えます。タイトル、冒頭文、日付、サムネイル画像は、書き出す記事から作ります。サムネイルは、はてなブログで設定したアイキャッチ画像（エクスポートの IMAGE: 行）を優先し、なければ本文の最初の画像を使います。
外部サイトOGP（タイトル・説明・画像・サイト名）を取得して、静的なカードHTMLにします。
OGP取得に失敗通常のリンクにします。
自分のブログだが書き出し対象外元URLの通常リンクにします（/archive/... や下書きなど）。

本文中の通常の <a href="自分の記事URL"> も、ローカルのパスに書き換えます。URL末尾の #アンカー は保持されます。

OGPキャッシュ

取得結果は ogp_cache.json に保存されます。再実行時は成功済みのURLを再取得しないので、2回目以降は速くなります。失敗したURLは記録され、--retry-failed を付けたときだけ再試行します。

オプション一覧

オプション説明既定値
inputMT形式のエクスポートファイル（必須）-
-o, --output出力ディレクトリsite
--titleサイトのタイトルマイブログ
--blog-url自分のブログのURLまたはホスト名（複数指定可）自動判定
--no-fetchOGPを取得しない取得する
--retry-failed前回失敗したURLを再試行しない
--cacheOGPキャッシュファイルogp_cache.json
--workersOGP取得の並列数4
--delay各リクエスト前の待機秒数0.3
--timeoutOGP取得のタイムアウト秒数10
--card-date-format内部記事カードに表示する日付の書式（例: "%Y年%m月%d日"）%Y-%m-%d
--list-date-format一覧ページの日付の書式%Y/%m/%d
--markdown本文をMarkdownとして変換しない

外部URLが多い場合は、相手サーバーへの負荷を抑えるために --workers を減らすか --delay を増やしてください。

一覧ページ（トップ・カテゴリ別）と検索

トップページとカテゴリ別ページには、それぞれ「テキスト一覧」と「画像付き一覧」があります。画面上部の「テキスト一覧 | 画像付き一覧」のリンクで、相互に切り替えられます。

  • index.html / index_image.html: 全記事の一覧です。表の上に、カテゴリ一覧（記事数つき）があります。
  • category/c1.html / category/c1_image.html: カテゴリごとの一覧です。

テキスト一覧は「カテゴリー」と「記事」の2列、画像付き一覧は「カテゴリー」と「記事」の間に、アイキャッチ画像の列を加えた表です。記事は新しい順で、タイトル（リンク）の後ろに、赤い文字で日付を表示します。

アイキャッチ画像

エクスポートの IMAGE: 行（はてなブログで設定したアイキャッチ画像）を使います。ない記事は、本文の最初の画像を使います。どちらもない記事は、薄い灰色の枠を表示します。

一覧ページの画像は、横×縦が4:3になるように、はみ出す部分を切り抜いて表示します（PCもスマホも同じ比率）。記事内のブログカードの画像は、横×縦が3:4（縦長）で、カードの右側いっぱいに表示します（カードの高さは画像がある場合132px固定、本文は最大2行）。比率を変えたいときは、style.css の aspect-ratio（一覧は td.col-img img、カードは .lc-thumb img）を編集してください。

検索

右上の検索ボックスに入力すると、カテゴリとタイトルを対象に、入力と同時に絞り込みます。一致した部分は、黄色の背景で強調されます。

  • スペースで区切ると、すべての語を含む記事だけに絞るAND検索になります（例: 野鳥 北海道）。
  • 英字の大文字・小文字と、全角・半角の違いは区別しません。
  • 検索は、ページに埋め込んだJavaScriptだけで動くので、サーバー側の仕組みは不要です。

一覧の日付の書式は --list-date-format で変えられます。

スマホでの表示

  • 表は列幅を固定し、長い英字やURLも折り返すので、画面の横幅をはみ出しません。
  • 画像付き一覧は、画面の幅が600px以下のとき、左に大きめの画像、右にタイトルと日付、その下にカテゴリを並べる表示に切り替わります。
  • 記事のタイトルは本文より少し大きい程度（PCで1.3倍、スマホで1.15倍）にしています。大きさを変えたいときは、style.css の article h1 の font-size を編集してください。

出力されるファイル

site/
├── index.html                  トップ（テキスト一覧・検索）
├── index_image.html            トップ（アイキャッチ画像つき一覧・検索）
├── style.css                   共通スタイル（ダークモード対応）
├── category/
│   ├── c1.html                 カテゴリ別の一覧（テキスト）
│   ├── c1_image.html           カテゴリ別の一覧（画像付き）
│   └── c2.html ...
└── entry/
    └── 2020/01/01/123456.html  記事（元の /entry/ 以下と同じ階層）

リンクはすべて相対パスなので、フォルダごと別の場所に移しても動作します。下書き（STATUS: Draft）は出力されません。

公開のしかた

site/ フォルダの中身を、GitHub Pages、Cloudflare Pages、Netlifyなどの静的ホスティングにアップロードします。

元のURL（/entry/2020/01/01/123456）と同じ形で配信したい場合は、.html を付けないURLで配信できるホストを選んでください。上記3つはこれに対応しています。

注意点・トラブルシューティング

記事が0件と表示される

公開状態（STATUS: Publish）の記事だけが対象です。ファイルがMT形式のエクスポートか、文字コードがUTF-8かを確認してください。

内部リンクがカードにならない

自分のブログのホストが正しく判定されていない可能性があります。実行時のメッセージを確認し、--blog-url で指定してください。独自ドメインとはてなのドメインの両方で記事が参照されている場合は、両方を指定します。

python3 hatena2static.py export.txt \
  --blog-url https://example.hatenablog.com \
  --blog-url https://blog.example.com

外部カードがリンクのみになる

相手サイトが閉鎖している、ボットのアクセスを拒否している、タイムアウトした、などの理由で取得に失敗しています。--timeout を増やして --retry-failed で再試行してみてください。取得結果は ogp_cache.json で確認できます。

画像について

本文中の画像と、カードのOGP画像は、外部のURLを直接参照します。はてなフォトライフの終了や、相手サイトの画像削除で表示されなくなる可能性があります。長期保存が目的の場合は、別途画像をダウンロードしてパスを書き換える処理が必要です。

はてな記法の記事

はてな記法で書かれた本文は変換できません。Markdownの記事は --markdown で変換できます。

本文に含まれるHTML（スクリプトを含む）はそのまま出力されます。ツイート埋め込みなどの外部スクリプトも、元のまま動作します。
