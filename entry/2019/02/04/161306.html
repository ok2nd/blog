備忘録：Windowsパソコンにインストールしているアプリケーションフリーソフト。自分にとって定番。

2019-02-04 · コンピュータ

Windowsパソコンに入れている主なアプリケーション・フリーソフトの一覧。再インストール時のための備忘録として。

■ 写真・画像関連

  • FastStone Image Viewer：画像表示
  • JTrim：画像編集・加工、トリミング
  • GIMP 2：画像編集・加工（アート加工）
  • Adobe Photoshop Express：画像編集・加工（アート加工）
  • SILKYPIX JPEG Photography 10：写真画像調整
  • FotoSketcher：画像編集・加工（アート加工）
  • ImageMagick：コマンドラインで使える画像編集
  • 縮小専用：画像縮小
  • 縮小革命：画像縮小
  • azure automatic（azure_auto）：画像自動回転
  • Ralpha Image Resizer：複数画像一括トリミング
  • Image Composite Editor：複数画像合成、超広角写真作成
  • ExifTool：EXIF情報抽出
  • DateFix：ファイルの更新日時を撮影日時に戻す
  • F6 Exif：撮影日時一括更新
  • トリミング de 顔写真！：画像を縦横比率でトリミング
  • uonome：魚眼レンズで撮った写真の歪みを補正
  • Screenpresso：画像に矢印を入れる
  • iMazing Converter：HEICからJPEGへの変換
  • Aiarty Image Enhancer：写真アップスケーリング
  • Upscayl：写真アップスケーリング

■ ファイル関連

  • Flexible Renamer：ファイルリネーム （不具合がある。Nameryと使い分け）
  • Namery：ファイルリネーム
  • Append TS2FN：ファイルリネーム（タイムスタンプをファイル名にする）
  • Lhaplus：ファイル圧縮・解凍
  • アタッシェケース４：ファイル暗号化
  • FastCopy：高速ファイルコピー
  • BunBackup：ファイルバックアップ
  • KH DeskKeeper：デスクトップアイコン位置保存
  • Send Anywhere：スマホ、iPadとのファイル転送
  • Change Timestamp（ctime）：タイムスタンプ一括変更
  • Q-Dir：フォルダー2画面、4画面同時表示
  • TreeSize Free：フォルダー内のファイル数一覧

■ ソフト開発、テキストファイル関連

  • TeraPad：テキストエディタ（絵文字など扱えないコードあり）
  • Mery：テキストエディタ
  • Devas：複数ファイルの文字列一括検索・置換
  • WinMerge：ファイルの差分チェックツール
  • DF：ファイルの差分チェックDiffツール（UTF-8未対応）
  • FFFTP：FTPツール
  • GitHub Desktop：GitHub ツール

■ PDF関連

  • CubePDF：PDF変換・作成
  • CubePDF Page：PDF結合・分割
  • CubePDF Utility：PDF 編集

■ 動画関連

  • MPC-BE：動画再生（同一フォルダの動画を前後ボタンで見られる）
  • VLC media player：動画再生・メディアプレイヤー
  • AG-デスクトップレコーダー：動画キャプチャ
  • Microsoft Clipchamp：動画編集
  • Video Clip QuickTool：動画のクロップ（矩形切り出し：Clipchampでも出来る）
  • Microsoftフォトレガシ「ビデオエディター」：動画結合
  • Free Video Joiner：動画結合（お勧めできない）
  • Giam：GIFアニメ作成
  • VideoProc Vlogger：2つの動画を横に並べた動画を作成（中国製）

■ ハードウェア診断

  • CrystalDiskInfo：HDDとSSDの健康診断（SMART情報のない外付SSD非対応）
  • CrystalDiskMark：SSDパフォーマンステスト
  • SSDLife Free：SSDの寿命予測（SSDが検出できない場合あり）

■ その他

  • Darkstar：Xerox Star 8010 エミュレーター
