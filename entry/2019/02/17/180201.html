以下のLightbox2を使用。

Lightbox2Lightbox is a script used to overlay images on the current page. It's …lokeshdhakar.com

使い方は簡単。CSSとJavaScriptを以下のように読み込んで、<div>を<a>タグで囲い、data-lightbox="group"を追加するだけ。

<link rel="stylesheet" href="lightbox/css/lightbox.min.css">
<script src="lightbox/js/lightbox-plus-jquery.min.js"></script>
<a href="拡大画像.jpg" data-lightbox="group" data-title="神戸散歩">
	<div class="box-frame"><div class="vignette"><img src="縮小画像.jpg"></div></div>
</a>
