【Windows アプリ FotoSketcher 3.30】

【Windows アプリ GIMP 2.10】

GIMPは機能が豊富なので、他に良い方法があるかもしれない。

バージョン2.10ではメニューが全て日本語化されていない。

手順として最初に、モノクロにする。

  • メニュー[画像] → モード → グレースケール

次にフィルタでエッジを抽出する。

  • メニュー[Filters] → Edge-Detect → Edge...

エッジを抽出したものを白黒反転する。InvertにはInvert、Linear Invert、Value Invertの3種類ある。Linear Invertを選んだ。

  • メニュー[色] → Linear Invert

Linear Invertで白黒反転したものをコントラスト調整。

  • メニュー[色] → Brightness-Contrast... → Contrastを最大の127に調整

Linear Invertで白黒反転したものを露出補正。

  • メニュー[色] → Exposure... → Exposureで＋4.0に補正
