Avira Browser Safetyを使うとGoogleマップのストリート ビューが表示されない

2016-06-14 · 地図・マップ コンピュータ

ブラウザ用セキュリティ対策ソフトAvira Browser Safetyを入れているとGoogle Maps JavaScript APIで作成したページのストリート ビューの画像が表示されない。下のようにグレーのみが表示されるようになる。（Google Chromeの場合。他のブラウザでは検証していない。）

Avira Browser Safetyの設定で、「Googleapis」のブロックを外せば、正常に表示されるようになる。

または、Google Chrome 設定の拡張機能で、Avira Browser Safetyの有効のチェックを外せば正常に表示されるようになる。

【後日追加】

Avira Browser Safetyを入れていると、他にも支障が出る場合がある。削除した方が良い。
