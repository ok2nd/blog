【追加ソースコード：縦方向ブラウザの高さ一杯に画像が入る】
<style>
img {
	height: 100%;
	object-fit: contain; /* アスペクト比固定 */
}
</style>

html, body, divなどにheight: 100%などを指定しても効果が無かったので、JavaScriptで画面の高さから50px引いた値をセットするようにした。

<script>
$(document).ready(function () {
	hsize = $(window).height() - 50;
	$(".container").css("height", hsize + "px");
});
$(window).resize(function () {
	hsize = $(window).height() - 50;
	$(".container").css("height", hsize + "px");
});
</script>
