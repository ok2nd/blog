上記（↑）の続き。

「MyHome Portal」の「ID管理」を、Python＋SQLiteの環境に移行するための作業。

「MyHome Portal」の「ID管理」データベース・データをCSVにエキスポートしたものを、SQLiteのデータベースにインポートするためのアプリをPythonで作成（Geminiで作成）。一部データは暗号化して格納。

暗号化したデータを複合化して一覧形式のGUI画面で表示するアプリも作成。

■ CSVデータをSQLiteデータベースにインポートするアプリ 1

c_val1～c_val8までのデータは、暗号化キーファイルを使って暗号化する。

  • データベース名：data/idManager.db
  • デーブル名：t_id_pass
  • 暗号化キーファイル：secret.key
  • CSV元データ：_mydb_zid_mgr_a.v_pass_for_csv（エクスポート用のビュー）
python 01-CSVtoSQLite_t_id_pass.py <CSVファイル>
■ CSVデータをSQLiteデータベースにインポートするアプリ 2
  • データベース名：data/idManager.db
  • デーブル名：t_category
  • CSV元データ：_mydb_zid_mgr_a.v_category（エクスポート用のビュー）
python 02-CSVtoSQLite_t_category.py <CSVファイル>
■ SQLiteデータベースの暗号化データも複合化して一覧表示するアプリ（開発用）

c_val1～c_val10までのデータは、暗号化キーファイルを使って復号化する。

  • 暗号化キーファイル：secret.key
  • マスターパスワードファイル：master.key（マスターパスワードを指定しないとアプリが実行できない。）
python view_db.py <データベースパス> <テーブル名> <マスターパスワード>

データベースパスのディレクトリ区切りは/でも\(￥)でも可能。
