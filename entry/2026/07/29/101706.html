活断層データを重ねて表示できるようにした。（↓）

※ 中央構造線断層帯は日本最長の断層帯で、J-SHISのデータ上は細かく分割された多数のセグメント（帯状のポリゴン）が隙間なく連続しているため、真っ赤になってしまう。

活断層をクリックすると、断層名をポップアップで表示する。

7月28日の熊本地震で動いたと言われている「日奈久断層帯」も表示される。

以下は、布田川・日奈久断層帯 - Wikipedia より

防災科学技術研究所「J-SHIS」の「主要活断層帯ベクトルタイル配信API」を使用。このデータは「主要活断層帯」（108〜114程度の帯状の面データ）が対象で、産総研DBの全活断層（約2000本超）を完全網羅するものではない。

  • 配信元：防災科学技術研究所（NIED）J-SHIS
    https://www.j-shis.bosai.go.jp/api-vectortile-majorfault
  • 形式：ベクトルタイル（MVT / Mapbox Vector Tile）
  • URL：https://www.j-shis.bosai.go.jp/map/xyz/major_fault/{version}/{case}/{z}/{x}/{y}.mvt
    • version：地図バージョン（例：Y2022）
    • case：AVR（平均ケース）またはMAX（最大ケース）
  • ズームレベル：4〜16
  • ライセンス：防災科研の公式APIとして無償公開

MVTはLeaflet標準では読み込めないため、Leaflet.VectorGridプラグインを追加。

<script src="https://unpkg.com/leaflet.vectorgrid@1.3.0/dist/Leaflet.VectorGrid.bundled.js"></script>
Overlay_Map[ 11 ] = L.vectorGrid.protobuf(
	'https://www.j-shis.bosai.go.jp/map/xyz/major_fault/Y2022/MAX/{z}/{x}/{y}.mvt',
	{
		maxNativeZoom: 16,
		minNativeZoom: 4,
		vectorTileLayerStyles: {
			major_fault: {
				weight: 1,		// 太さ
				color: '#e6001a',
				opacity: 0.6,		// 線の濃さ
				fillColor: '#e6001a',
				fillOpacity: 0.1,	// 塗りつぶしの濃さ
				fill: true		// 塗りつぶし
			}
		},
		interactive: true,
		attribution: '防災科学技術研究所（J-SHIS）：主要活断層帯ベクトルタイル'
	}
);
// クリックで断層名をポップアップ表示（任意）
Overlay_Map[ 11 ].on('click', function (e) {
	var props = e.layer.properties;
	if (props && props.LTENAME) {
		L.popup()
			.setLatLng(e.latlng)
			.setContent(props.LTENAME)
			.openOn(map);
	}
});
