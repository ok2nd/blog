Python）Windows）画像アニメーションファイル（ GIF / APNG / AVIF / WebP / MP4 ）作成アプリ。

2026-03-22 · 写真・カメラ コンピュータ ホームページ、Web作成

今まで、GIFアニメ作成には、Webサイト「フォトコンバイン：GIFアニメーション画像作成ツール」や、Windowsアプリ「Giam」を使用していた。

どちらも使いづらい面があったので、シンプルかつ、その他のアニメーション対応ファイル形式も作成できるWindowsアプリをPythonで作成した。生成AI「Claude」使用。

作成できるアニメーション対応ファイル形式。

  • GIF（GIFアニメ）
  • APNG（アニメーションPNG）
  • AVIF
  • WebP
  • MP4（動画）
形式 登場年 色数 圧縮方式 アニメーション 透過（アルファ） ファイルサイズ ブラウザ対応 おすすめ用途
GIF 1987年 256色 ロスレス（LZW） ○ ○（1色のみ） 中 全ブラウザ 汎用・SNS・レガシー環境
APNG 2008年 フルカラー ロスレス（zlib） ○ ○（半透明も可） 大 全モダンブラウザ フルカラー・透過アニメ
AVIF 2019年 フルカラー（HDR対応） 非可逆／ロスレス選択可（AV1） ○ ○（半透明も可） 最小級（WebPより小） Chrome・Firefox・Safari（Edge一部） 最高画質・最小サイズ（最新環境）
WebP 2010年 フルカラー 非可逆／ロスレス選択可 ○ ○（半透明も可） 最小級 全モダンブラウザ 小サイズ優先・Web全般
WebM 2010年 フルカラー 非可逆（VP8/VP9/AV1） ○（動画） ○（アルファチャンネル） 小 全モダンブラウザ（videoタグ） 透過動画・Web動画配信
MP4 2001年 フルカラー 非可逆（H.264/H.265） ○（動画） △（H.265のみ） 小〜中 全ブラウザ（videoタグ） 動画プレイヤー・高画質保存
SVG 1999年 フルカラー（ベクター） テキスト（XML） ○（CSS/SMILアニメ） ○ 極小（図形・ロゴ向け） 全ブラウザ ロゴ・アイコン・図形アニメ
MNG 2001年 フルカラー ロスレス（zlib） ○ ○ 大 ほぼ非対応（廃れた） 現在はほぼ使われない
■ アニメーションファイル作成結果ファイルサイズ

今回作成したツールで、アニメーションファイルを作成した結果のファイルサイズは以下。AVIFが圧倒的に小さい。GIFアニメは、最大256色しかサポートしていないので、サイズが大きい割に画質が落ちる。

  • 元JPEG画像画素数：800x631ピクセル
  • 元JPEG画像1枚のファイルサイズ：170KB前後
  • 元JPEG画像枚数：11枚
  • フレームレート：15
形式 ファイルサイズ
GIF 4.46MB
APNG 9.83MB
AVIF 243KB
WebP 1.16MB
MP4 639KB
■ はてなブログ対応

はてなブログでは、GIFアニメ以外は、正しくアニメ表示できない。

■ Pythonアプリ
  • アプリのウインドウに、複数画像をドラッグ＆ドロップする。
  • フレームレートを1～30で指定できる。初期値は15。
  • ループ設定：無限ループ。（MP4は対象外）
  • 作成ボタンを押すと、それぞれのフォルダー（ GIF / APNG / AVIF / WebP / MP4 ）を作成し、その中にアニメーションファイルを作成する。
  • アニメーションファイル名にフレームレートを入れる。

    # ──────────────────────────────────────────
    # 形式変更時にボタンのラベル・色を更新
    # ──────────────────────────────────────────
    def _on_fmt_change(self):
        fmt = self.fmt_var.get()
        info = FORMATS[fmt]
        icons = {"gif": "🎞", "apng": "🖼", "avif": "✨", "webp": "🌐", "mp4": "🎬"}
        self.make_btn.config(

            activebackground=info["color"]

    # ──────────────────────────────────────────
    # ドロップ処理
    # ──────────────────────────────────────────
    def _on_drop(self, event):
        paths = self._parse_drop_data(event.data)
        added = 0
        for p in paths:
            ext = os.path.splitext(p)[1].lower()
            if ext in (".jpg", ".jpeg") and p not in self.image_paths:
                self.image_paths.append(p)
                self.listbox.insert("end", os.path.basename(p))
                added += 1
        self._update_status(f"{added} 件追加しました（合計 {len(self.image_paths)} 件）")
        self._update_count()

    def _parse_drop_data(self, raw: str) -> list:
        result = []
        curly = re.findall(r'\{([^}]+)\}', raw)
        remainder = re.sub(r'\{[^}]+\}', '', raw).strip()
        result.extend(curly)
        if remainder:
            result.extend(remainder.split())
        return [p.strip() for p in result if p.strip()]

    # ──────────────────────────────────────────
    # リスト操作
    # ──────────────────────────────────────────
    def _clear_list(self):
        self.image_paths.clear()
        self.listbox.delete(0, "end")
        self._update_status("リストをクリアしました")
        self._update_count()

    def _remove_selected(self):
        sel = self.listbox.curselection()
        if not sel:
            return
        idx = sel[0]
        self.listbox.delete(idx)
        del self.image_paths[idx]
        self._update_count()

    def _move_up(self):
        sel = self.listbox.curselection()
        if not sel or sel[0] == 0:
            return
        i = sel[0]
        self.image_paths[i - 1], self.image_paths[i] = self.image_paths[i], self.image_paths[i - 1]
        self._refresh_listbox(i - 1)

    def _move_down(self):
        sel = self.listbox.curselection()
        if not sel or sel[0] >= len(self.image_paths) - 1:
            return
        i = sel[0]
        self.image_paths[i + 1], self.image_paths[i] = self.image_paths[i], self.image_paths[i + 1]
        self._refresh_listbox(i + 1)

    def _refresh_listbox(self, select_idx=None):
        self.listbox.delete(0, "end")
        for p in self.image_paths:
            self.listbox.insert("end", os.path.basename(p))
        if select_idx is not None:
            self.listbox.selection_set(select_idx)
            self.listbox.see(select_idx)

    def _update_count(self):
        self.count_label.config(text=f"{len(self.image_paths)} 件")

    # ──────────────────────────────────────────
    # FPS 操作
    # ──────────────────────────────────────────
    def _fps_inc(self):
        v = self.fps_var.get()
        if v < 30:
            self.fps_var.set(v + 1)

    def _fps_dec(self):
        v = self.fps_var.get()
        if v > 1:
            self.fps_var.set(v - 1)

    def _get_fps(self) -> int:
        try:
            v = int(self.fps_entry.get())
            return max(1, min(30, v))
        except ValueError:
            return 15

    # ──────────────────────────────────────────
    # アニメーション生成（共通エントリ）
    # ──────────────────────────────────────────
    def _make_animation(self):
        if not self.image_paths:
            messagebox.showwarning("ファイルなし", "JPEGファイルをドロップしてください。")
            return

        fmt  = self.fmt_var.get()
        fps  = self._get_fps()
        info = FORMATS[fmt]

        first_path = self.image_paths[0]
        parent_dir = os.path.dirname(first_path)
        out_dir    = os.path.join(parent_dir, info["subdir"])
        os.makedirs(out_dir, exist_ok=True)

        base_name = os.path.splitext(os.path.basename(first_path))[0]
        out_name  = f"{base_name}-{fps}{info['ext']}"
        out_path  = os.path.join(out_dir, out_name)

        self._update_status(f"{info['label']} を生成中...")
        self.update()

        try:
            if fmt == "gif":
                self._save_gif(out_path, fps)
            elif fmt == "apng":
                self._save_apng(out_path, fps)
            elif fmt == "avif":
                self._save_avif(out_path, fps)
            elif fmt == "webp":
                self._save_webp(out_path, fps)
            elif fmt == "mp4":
                self._save_mp4(out_path, fps)

            size_kb = os.path.getsize(out_path) // 1024
            self._update_status(
                f"✅ 完了: {out_name}  "
                f"（{len(self.image_paths)} フレーム / {fps} fps / {size_kb} KB）"
            )
            messagebox.showinfo(
                "完了",
                f"{info['label']}を生成しました！\n\n"
                f"保存先: {out_path}\n"
                f"フレーム数: {len(self.image_paths)}\n"
                f"フレームレート: {fps} fps\n"
                f"ファイルサイズ: {size_kb} KB"
            )
        except Exception as e:
            self._update_status(f"❌ エラー: {e}")
            messagebox.showerror("エラー", f"{info['label']}の生成に失敗しました。\n\n{e}")

    # ──────────────────────────────────────────
    # GIF 保存
    # ──────────────────────────────────────────
    def _save_gif(self, out_path: str, fps: int):
        duration_ms = int(1000 / fps)
        frames = []
        for p in self.image_paths:
            img   = Image.open(p).convert("RGB")
            img_p = img.quantize(colors=256, method=Image.Quantize.MEDIANCUT)
            frames.append(img_p)

        frames[0].save(
            out_path,
            format="GIF",
            save_all=True,
            append_images=frames[1:],
            duration=duration_ms,
            loop=0,
            optimize=True
        )

    # ──────────────────────────────────────────
    # APNG 保存（フルカラー・ロスレス）
    # ──────────────────────────────────────────
    def _save_apng(self, out_path: str, fps: int):
        duration_ms = int(1000 / fps)
        frames = []
        base_size = None
        for p in self.image_paths:
            img = Image.open(p).convert("RGBA")
            if base_size is None:
                base_size = img.size
            elif img.size != base_size:
                img = img.resize(base_size, Image.LANCZOS)
            frames.append(img)

        frames[0].save(
            out_path,
            format="PNG",
            save_all=True,
            append_images=frames[1:],
            duration=duration_ms,
            loop=0,
            optimize=False
        )

    # ──────────────────────────────────────────
    # AVIF アニメーション保存
    # ──────────────────────────────────────────
    def _save_avif(self, out_path: str, fps: int):
        try:
            import pillow_avif  # noqa: F401
        except ImportError:
            raise RuntimeError(
                "AVIF 出力には pillow-avif-plugin が必要です。\n"
                "コマンドプロンプトで以下を実行してください:\n"
                "  pip install pillow-avif-plugin"
            )

        duration_ms = int(1000 / fps)
        frames = []
        base_size = None
        for p in self.image_paths:
            img = Image.open(p).convert("RGB")
            if base_size is None:
                base_size = img.size
            elif img.size != base_size:
                img = img.resize(base_size, Image.LANCZOS)
            frames.append(img)

        frames[0].save(
            out_path,
            format="AVIF",
            save_all=True,
            append_images=frames[1:],
            duration=duration_ms,
            loop=0,
            quality=60        # 0（最高圧縮）〜100（最高品質）
        )

    # ──────────────────────────────────────────
    # WebP アニメーション保存
    # ──────────────────────────────────────────
    def _save_webp(self, out_path: str, fps: int):
        try:
            import webp as webplib
        except ImportError:
            raise RuntimeError(
                "WebP 出力には webp パッケージが必要です。\n"
                "コマンドプロンプトで以下を実行してください:\n"
                "  pip install webp"
            )

        duration_ms = int(1000 / fps)
        pil_frames = []
        base_size = None
        for p in self.image_paths:
            img = Image.open(p).convert("RGB")
            if base_size is None:
                base_size = img.size
            elif img.size != base_size:
                img = img.resize(base_size, Image.LANCZOS)
            pil_frames.append(img)

        w, h = base_size
        enc_opts = webplib.WebPAnimEncoderOptions.new()
        enc_opts.loop_count = 0
        encoder = webplib.WebPAnimEncoder.new(w, h, enc_opts)
        config = webplib.WebPConfig.new(quality=85)

        for i, img in enumerate(pil_frames):
            pic = webplib.WebPPicture.from_pil(img)
            encoder.encode_frame(pic, i * duration_ms, config)

        anim_data = encoder.assemble(len(pil_frames) * duration_ms)
        with open(out_path, "wb") as f:
            f.write(bytes(anim_data.buffer()))

    # ──────────────────────────────────────────
    # MP4 保存
    # ──────────────────────────────────────────
    def _save_mp4(self, out_path: str, fps: int):
        try:
            import cv2
            import numpy as np
        except ImportError:
            raise RuntimeError(
                "MP4 出力には opencv-python が必要です。\n"
                "コマンドプロンプトで以下を実行してください:\n"
                "  pip install opencv-python"
            )

        first = Image.open(self.image_paths[0]).convert("RGB")
        w, h = first.size
        nw = w - (w % 2)
        nh = h - (h % 2)

        fourcc = cv2.VideoWriter_fourcc(*"mp4v")
        writer = cv2.VideoWriter(out_path, fourcc, fps, (nw, nh))
        if not writer.isOpened():
            raise RuntimeError("VideoWriter を開けませんでした。")

        try:
            for p in self.image_paths:
                img = Image.open(p).convert("RGB")
                if img.size != (nw, nh):
                    img = img.resize((nw, nh), Image.LANCZOS)
                frame_bgr = cv2.cvtColor(np.array(img), cv2.COLOR_RGB2BGR)
                writer.write(frame_bgr)
        finally:
            writer.release()
