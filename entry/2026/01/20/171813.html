Leaflet地図：地点名、住所検索「L.Control.OSMGeocoder」廃止。「Leaflet Control Geocoder」に置き換え。

2026-01-20 · 地図・マップ ホームページ、Web作成

Leaflet地図で、地点名、住所検索に「L.Control.OSMGeocoder」を使っていたが、廃止されたようだ。

代替として「Leaflet Control Geocoder」に置き換え。

Leaflet の公式プラグインリストでも推奨されている、事実上の標準プラグイン。OSM (Nominatim) をデフォルトで使用でき、Google Maps や Bing などの他のエンジンにも対応している。

【削除コード】
<script src="//rawgit.com/k4r573n/leaflet-control-osm-geocoder/master/Control.OSMGeocoder.js"></script>
<link rel="stylesheet" href="//rawgit.com/k4r573n/leaflet-control-osm-geocoder/master/Control.OSMGeocoder.css">

var osmGeocoder = new L.Control.OSMGeocoder({
	collapsed: false,
	text: '検索',
	placeholder: '地点名を入力してください。',
	callback: function (results) {
		var coords = L.latLng(results[0].lat,results[0].lon);
		var foundIcon = L.divIcon({ className: 'found-icon', iconAnchor: [8, 8] });
		L.marker(coords, {icon: foundIcon}).addTo(map);
		map.setView(coords,17);
	}
});
map.addControl(osmGeocoder);

【差し替えコード】

※ イベントの受け取り方: callback オプションではなく、.on('markgeocode', function(e) { ... }) というイベントリスナー形式で記述するのが現在の標準。

※ 座標のプロパティ: results[0].lat のような配列アクセスではなく、e.geocode.center で直接 L.latLng オブジェクトが取得できる。

※ デフォルトマーカーの制御: 新しいプラグインは検索時に自動でマーカーを立てる機能がある。自分の foundIcon を使いたい場合は defaultMarkGeocode: false に設定する。

<script src="https://unpkg.com/leaflet-control-geocoder/dist/Control.Geocoder.js"></script>
<link rel="stylesheet" href="https://unpkg.com/leaflet-control-geocoder/dist/Control.Geocoder.css" />
var geocoder = L.Control.geocoder({
	defaultMarkGeocode: false, // デフォルトのマーカー表示を無効化
	collapsed: false,
	placeholder: '地点名を入力してください。',
})
.on('markgeocode', function(e) {
	// 検索結果を取得
	var result = e.geocode;
	var coords = result.center; // L.latLng オブジェクトが返される
	// カスタムアイコンの作成
	var foundIcon = L.divIcon({ 
		className: 'found-icon', 
		iconAnchor: [8, 8] 
	});
	// マーカーを追加して移動
	L.marker(coords, { icon: foundIcon }).addTo(map);
	map.setView(coords, 17);
})
.addTo(map);
