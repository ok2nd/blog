無料でPHP＋MySQLが使えるWebホスティングサーバー「InfinityFree」を使ってみた。既存サービスからの移行検証。

2026-01-19 · ホームページ、Web作成

無料でPHP＋MySQLが使えるWebホスティングサーバーは、いくつもあるようだ。

  • InfinityFree
  • GoogieHost
  • x10Hosting
  • Free-Hosting.org
  • ProPHP Free Hosting
  • Ultimatefreehost

この中から「InfinityFree」を使ってみた。

「GoogieHost」はレスポンスは速いらしいが、管理画面への15日間の非ログインで凍結される（？）らしいので、諦めた。

※ 後日追記：「InfinityFree」で無料で立ち上げたWebページは2か月程で、ドメイン停止になった。途中で、管理画面へのログインはしてしたが、効果なかった。後日試した「x10Hosting」の方が良いかもしれない。

※ 後日追記：海外のサーバーを使う場合、サーバーの時刻（タイムゾーン）が日本にはなっていない。そのため、システムを構築するにあたっては、その点を考慮する必要がある。PHPでシステム作成する場合、日本時間を設定すること。一般的にconfig.php等に記入する。

date_default_timezone_set('Asia/Tokyo');

  • 無料で PHP & MySQL（MariaDB）対応。
  • 5GB のディスク & 無制限帯域。
  • 400 個の MySQL データベースが作れる（？）。
  • 1つの「クライアントエリア」ログインで最大3つまでの無料ホスティングアカウント（サイトアカウント）を作成できる。
  • 無料 SSL（HTTPS）対応。
  • Webページに広告が表示されない。（管理画面には出る。）
  • アカウント作成にクレジットカード情報などを求められない。
  • 定期的（3か月ごとなど）な契約更新手続きは必要ない。
  • 過去30日間に一定数（目安として5件以上）のアクセスがない場合、アカウントは「休止状態（Inactive）」とみなされ、自動的にSuspended（停止）される。停止された後、一定期間（約20～60日程度）放置すると、サーバー上のデータは完全に削除される。
  • 英国拠点の会社iFastNetが2016年9月からサービス提供。iFastNet社は20年以上のホスティング経験あり。

高負荷なサービスには使えないが、ちょっとした個人的なWebサービスには使えそう。

「さくらインターネット」で運用している個人的なカレンダー＆スケジューラを移行してみた。

「さくらインターネット」のサイトに比べて、応答速度は落ちる。データベースへの更新結果が画面に反映されるまで時間がかかる（2秒程度？）。

【以下実際にやってみた手順】

■ InfinityFreeアカウント作成。

  1. Googleアカウントでログイン。
  2. 「Create Account」ボタンを押す。

  3. 任意のSubdomain名を入れて、Domain Extensionを複数の中から自分の好きなものを選択。

  4. アカウント生成する。UsernameやPasswordは自動生成される。

■ 作成されたアカウントのクライアントエリア。

「View Site」をクリックすると、以下のような画面が表示される。

■ PHPファイルのアップロード：File Manager

※「File Manager」を使う。

■ PHPファイルのアップロードはフォルダー一括でもできる。

■ PHPファイルの修正もできる。

■ PHPファイルのアップロード：FTP

※ File Managerでアップロードできないファイルがある。

その場合、FTPを使う。「FTP Details」に、以下の項目がある。

  • FTP Username
  • FTP Password
  • FTP Hostname
  • FTP Port

■ MySQL データベース設定

※「Control Panel」を開く。

「Control Panel」を下にスクロールして、「DATABASE」の「MySQL Database」を選択。

データベース名を入れる。実際のデータベース名は、自動で接頭辞がついた形になる。

■ phpMyAdmin

上記の「Current Databases」の「Admin」ボタンを押すと、「phpMyAdmin」のページが開く。

■ データベースを別サーバーから移行

※ 「phpMyAdmin」のページを使う。

「さくらインターネット」で運用しているデータベースから、必要なテーブルをエクスポートしたSQLファイル（「CREATE TABLE」、「INSERT INTO テーブル」）を、インポートする。

CREATE TABLE IF NOT EXISTS `tbl_schedule` (
  `id_schedule` int(10) unsigned NOT NULL AUTO_INCREMENT,
  `id_account` varchar(20) NOT NULL,
  `c_date` datetime NOT NULL,
  `c_date2` datetime DEFAULT NULL,
  `c_color` varchar(20) NOT NULL,
  `c_memo` varchar(256) NOT NULL,
  `c_delete` int(10) unsigned DEFAULT NULL,
  `c_registtime` datetime NOT NULL,
  PRIMARY KEY (`id_schedule`)
) ENGINE=InnoDB  DEFAULT CHARSET=utf8mb4 AUTO_INCREMENT=254 ;

■ PHPプログラムのMySQL接続部分の修正

※ 以下の記述をInfinityFreeに合わせて修正。

define('DB_SERVER', 'xxxxxxx.com');
define('DB_USER', 'xxxxxxx');
define('DB_PASSWORD', 'xxxxxxx');
define('DB_NAME', 'xxxxxxx_calendar');
$conn = mysqli_connect(DB_SERVER, DB_USER, DB_PASSWORD, DB_NAME);

MySQLのパスワードは、クライアントエリアの右側「Account Details」の中にある。

■ PHPのMySQL関係の関数を修正。

「さくらインターネット」で運用していたPHPは古いバージョンで作成した。

現在の PHP（バージョン 7.0 以上）では古い「mysql_」系の関数が廃止されてる。新しいバージョンでは「mysqli_」系に修正する必要がある。

  • 旧：「mysql_xxxxx」
  • 新：「mysqli_xxxxx」

「InfinityFree」では、古いバージョンには対応していないので、MySQL関係の関数をすべて書き直す必要がある。引数に「$conn」が必要になったものが多い。

［新旧例］

  • 旧：mysql_select_db($db)
  • 新：mysqli_select_db($conn, $db)
