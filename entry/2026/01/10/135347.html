Python）Windowsのエクスプローラーを2画面左右に並べて開くツール作成。Windows11のスナップ機能を使わずに実現。

2026-01-10 · コンピュータ

Windowsのエクスプローラーを2画面左右に並べて開きたい。

こういった機能のツールアプリは色々あるが、余分な機能があって使いづらい。

単純に、エクスプローラーを2画面左右に並べて開くだけのツールをPythonで作成した。

※ Windows11のスナップ機能を使わずに実現。

【ライブラリの追加】
pip install pygetwindow screeninfo
【Pythonツールのコード】
import subprocess
import time
import pygetwindow as gw
from screeninfo import get_monitors

def open_dual_explorer_fixed():
    # メインモニターの解像度を取得
    monitor = get_monitors()[0]
    width = monitor.width
    height = monitor.height - 40  # タスクバー分を考慮

    # 1つ目のエクスプローラーを起動
    subprocess.Popen(r'explorer /n,"C:\"') # 任意のフォルダーに変更
    time.sleep(1.5) # 起動待ち（PCの速度に合わせて調整）
    
    # 2つ目のエクスプローラーを起動
    subprocess.Popen(r'explorer /n,"C:\"') # 任意のフォルダーに変更
    time.sleep(1.0)

    # 開いたエクスプローラーをすべて取得
    explorers = [w for w in gw.getWindowsWithTitle('エクスプローラー') if w.visible]

    # Windows11のウィンドウには、見た目よりも数ピクセル外側に透明な境界線が存在する
    # 左右のウィンドウをそれぞれ少しだけ(例: 7ピクセル)太らせて調整
    padding = 7

    # 最新の2つを左右に配置
    if len(explorers) >= 2:
        # 左側に配置
        explorers[0].restore() # 最小化されていれば元に戻す
        explorers[0].moveTo(0 - padding, 0)
        explorers[0].resizeTo(width // 2 + padding, height)
        
        # 右側に配置
        explorers[1].restore()
        explorers[1].moveTo(width // 2 - (padding * 2), 0)
        explorers[1].resizeTo(width // 2 + (padding * 3), height)

if __name__ == "__main__":
    open_dual_explorer_fixed()
