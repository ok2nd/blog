「MyHome Portal」の「預貯金管理」は、自分で作成したシステムだが、問題なく使えていて、使い勝手も良いが、将来にわたって、PHP、MySQLの環境管理含めて維持することに不安があるため、Python＋SQLiteで、アプリを再作成してデータ移行。

アプリは、生成AI「Claude」にて作成。

※ 下の画面イメージは、サンプル用のダミーデータ。

■１． SQLite データベース：テーブル作成

データベース：data/預貯金管理.db

-- 預貯金
CREATE TABLE IF NOT EXISTS t_chokin (
    id_chokin       INTEGER PRIMARY KEY,
    id_ginkou       INTEGER,
    c_kinyuShohin   TEXT,
    c_keiyakuSha    TEXT,
    c_keiyakuKin    INTEGER,
    c_keiyakuYMD    TEXT,
    c_ritsu         REAL,
    c_mankiYMD      TEXT,
    c_registtime    TEXT,
    c_updatetime    TEXT,
    c_delete        INTEGER,
    id_shurui       INTEGER,
    id_mankitype    INTEGER
);

-- 銀行
CREATE TABLE IF NOT EXISTS t_ginkou (
    id_ginkou              INTEGER PRIMARY KEY,
    c_ginkouName           TEXT,
    c_ginkouDisplayOrder   INTEGER
);

-- 満期タイプ
CREATE TABLE IF NOT EXISTS t_mankitype (
    id_mankitype    INTEGER PRIMARY KEY,
    c_mankitype     TEXT
);

-- 種類
CREATE TABLE IF NOT EXISTS t_shurui (
    id_shurui   INTEGER PRIMARY KEY,
    c_shurui    TEXT
);

-- 預貯金ビュー
CREATE VIEW IF NOT EXISTS v_chokin AS
SELECT
    c.*,
    g.c_ginkouName,
    g.c_ginkouDisplayOrder,
    m.c_mankitype,
    s.c_shurui
FROM t_chokin AS c
LEFT JOIN t_ginkou AS g
    ON c.id_ginkou = g.id_ginkou
LEFT JOIN t_mankitype AS m
    ON c.id_mankitype = m.id_mankitype
LEFT JOIN t_shurui AS s
    ON c.id_shurui = s.id_shurui;
