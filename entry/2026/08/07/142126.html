Leaflet地図：「南海トラフ巨大地震」想定震度（内閣府、J-SHIS）を重ねて表示（オーバレイ）。

2026-08-07 · 地図・マップ ホームページ、Web作成

Leaflet地図に、「南海トラフ巨大地震」想定震度（内閣府、J-SHIS）を重ねて表示（オーバレイ）できるようにした。

内閣府「南海トラフ巨大地震モデル検討会」の公表データ（基本ケース・陸側ケース等の最大値）および防災科学技術研究所（J-SHIS）の震度分布を元に集約した代表値を使っている。想定震度は、モデルの違いで大きく変わる点に注意が必要。

※ 今回使用したデータは、内閣府の有識者会議などが提示しているモデルで、「千年に一度」クラスのあらゆる可能性を考慮した最悪のシナリオなので、想定震度が最大クラスになっている

※ 気象庁のホームページに載っているのは、過去に実際に起きた地震と同規模の破壊パターンを再現したモデルなので、想定震度は低めに現されている。以下の図は、気象庁ホームページのもの。

https://ok2nd.github.io/leaflet/me5.html

右側のプルダウンメニューで、「南海トラフ巨大地震 想定震度」にチェックを入れる。

九州南部から東海地方にかけての太平洋側沿岸部などで最大震度7、九州から近畿・東海、関東一部にかけての広い地域で震度6強から6弱が想定されている。

建物が大きな被害を免れたとしても、電気・ガス・水道・通信・道路などのインフラには甚大な被害が生じる可能性が高い。被災範囲が極めて広いため、近隣の市町村から十分な応援を受けることも容易ではない。

津波浸水想定のハザードマップも合わせて表示することもできる。

<style>
.shindo-badge {	/* 南海トラフ想定震度マーカー */
	display: flex;
	align-items: center;
	justify-content: center;
	width: 26px;
	height: 26px;
	border-radius: 50%;
	border: 2px solid #fdfdfd;
	box-shadow: 1px 1px 4px rgba(0, 0, 0, 0.7);
	font-size: 12px;
	font-weight: bold;
	font-family: sans-serif;
}
</style>
<script>
// 南海トラフ巨大地震 想定震度マーカー（パネルでチェックした時のみ表示）
var nankaiTroughLayer = L.layerGroup();	// 最初は地図に addTo しない＝非表示状態
var shindoStyle = {	// 震度ごとの色・文字色・表示ラベル（JMA震度階級の配色に準拠）
	'震度1':   { color: '#F2F2FF', text: '#000', label: '1'  },
	'震度2':   { color: '#00AAFF', text: '#000', label: '2'  },
	'震度3':   { color: '#00FF00', text: '#000', label: '3'  },
	'震度4':   { color: '#FFFF00', text: '#000', label: '4'  },
	'震度5弱': { color: '#FF9600', text: '#000', label: '5-' },
	'震度5強': { color: '#FF6000', text: '#fff', label: '5+' },
	'震度6弱': { color: '#FF0000', text: '#fff', label: '6-' },
	'震度6強': { color: '#C00000', text: '#fff', label: '6+' },
	'震度7':   { color: '#960099', text: '#fff', label: '7'  }
};
function loadNankaiTrough() {
	fetch('csv/nankai-trough-earthquake.csv')
	.then(function(res) {
		return res.text();
	})
	.then(function(text) {
		var lines = text.split(/\r?\n/).filter(function(line) {
			return line.trim() !== '';
		});
		// 1行目はヘッダーなのでスキップ
		// 列構成：全国地方公共団体コード,都道府県名,市区町村名,代表緯度,代表経度,南海トラフ巨大地震想定震度
		for (var i = 1; i < lines.length; i++) {
			var cols = lines[i].split(',');
			if (cols.length < 6) { continue; }
			var pref = cols[1];
			var city = cols[2];
			var lat = parseFloat(cols[3]);
			var lng = parseFloat(cols[4]);
			var shindo = cols[5].trim();
			var style = shindoStyle[shindo];
			if (!style || isNaN(lat) || isNaN(lng)) { continue; }
			var html = '<div class="shindo-badge" style="background-color:' + style.color + ';color:' + style.text + ';">' + style.label + '</div>';
			var icon = L.divIcon({ className: '', html: html, iconSize: [26, 26], iconAnchor: [13, 13] });
			L.marker([lat, lng], { icon: icon })
				.bindPopup(pref + city + '<br>南海トラフ巨大地震 想定震度：' + shindo)
				.addTo(nankaiTroughLayer);
		}
	})
	.catch(function(err) {
		console.error('南海トラフ震度データの読み込みに失敗しました。', err);
	});
}
loadNankaiTrough();	// ページ読み込み時に一度だけ取得（表示はレイヤーパネルのチェック操作に連動）
</script>
