Font Awesome とは

Font Awesome は、アイコンをフォントとして提供するライブラリである。画像ファイルは不要で、<i> タグにクラスを付けるだけで表示できる。CSS の color や font-size でそのまま制御できるのが最大の利点だ。

無償の Free エディションと有償の Pro エディションがある。CDN を1行読み込むだけで始められる。

<link rel="stylesheet"
      href="https://cdnjs.cloudflare.com/ajax/libs/font-awesome/6.5.2/css/all.min.css">

基本の使い方

<i> タグにスタイルクラスとアイコン名クラスを付与する。スタイルクラスは3種類ある。

クラス 種別 内容
fa-solid Solid 塗りつぶしアイコン（最も種類が多い）
fa-regular Regular 輪郭のみのアイコン
fa-brands Brands 企業・サービスのロゴ 
<i class="fa-solid fa-house"></i>       <!-- Solid -->
<i class="fa-regular fa-star"></i>     <!-- Regular -->
<i class="fa-brands fa-github"></i>    <!-- Brands -->

サイズ変更

組み込みクラス fa-xs 〜 fa-2xl、または CSS の font-size で指定する。

<i class="fa-solid fa-location-dot fa-xs"></i>
<i class="fa-solid fa-location-dot fa-lg"></i>
<i class="fa-solid fa-location-dot fa-2xl"></i>
<i class="fa-solid fa-location-dot" style="font-size:48px"></i>

色変更

CSS の color プロパティで着色する。親要素の色も継承する。

<i class="fa-solid fa-star" style="color:#3b6ef6"></i>
<i class="fa-solid fa-star" style="color:#e84393"></i>

アニメーション

<i class="fa-solid fa-spinner fa-spin"></i>   <!-- 回転 -->
<i class="fa-solid fa-bell fa-shake"></i>     <!-- 振動 -->
<i class="fa-solid fa-heart fa-beat"></i>     <!-- 鼓動 -->

アイコンを重ねる（fa-stack）

fa-stack コンテナで2つのアイコンを重ね合わせられる。

<span class="fa-stack">
  <i class="fa-solid fa-circle fa-stack-2x" style="color:#3b6ef6"></i>
  <i class="fa-solid fa-map-pin fa-stack-1x fa-inverse"></i>
</span>

Leaflet との組み合わせ

Leaflet は軽量な OSS の地図ライブラリである。L.divIcon を使うと任意の HTML をマーカーにできるため、Font Awesome のアイコンをそのままピンとして地図上に置ける。

const icon = L.divIcon({
  html: '<i class="fa-solid fa-location-dot" style="font-size:32px;color:#e84393"></i>',
  iconSize:   [32, 32],
  iconAnchor: [16, 32],   // アイコン下端を座標に合わせる
  className:  ''           // デフォルトの白背景を除去
});

L.marker([35.6812, 139.7671], { icon }).addTo(map).bindPopup('東京駅');

className: '' を指定しないと Leaflet のデフォルトスタイル（白背景・枠線）が残るので注意。ポップアップ内でも <i> タグをそのまま使える。

marker.bindPopup('<i class="fa-solid fa-utensils"></i> レストラン');

easy-button.js との組み合わせ

easy-button.js は Leaflet 用プラグインで、地図のコントロール領域（ズームボタンの隣）にカスタムボタンをワンライナーで追加できる。Font Awesome のクラス名を第1引数に渡すだけでアイコンボタンが完成する。

CDN での読み込み（3点セット）

<!-- Leaflet -->
<link rel="stylesheet" href="https://unpkg.com/leaflet@1.9.4/dist/leaflet.css">
<script src="https://unpkg.com/leaflet@1.9.4/dist/leaflet.js"></script>

<!-- Font Awesome（Leaflet より先に読み込む）-->
<link rel="stylesheet"
      href="https://cdnjs.cloudflare.com/ajax/libs/font-awesome/6.5.2/css/all.min.css">

<!-- easy-button -->
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/leaflet-easybutton@2/src/easy-button.css">
<script src="https://cdn.jsdelivr.net/npm/leaflet-easybutton@2/src/easy-button.js"></script>

単ボタンの追加

L.easyButton(
  'fa-solid fa-location-crosshairs',   // Font Awesome クラス名
  function(btn, map) {
    map.locate({ setView: true, maxZoom: 16 });
  },
  '現在地に移動'                        // ツールチップ
).addTo(map);

トグルボタン（状態切り替え）

states に複数の状態を渡すと、クリックのたびにアイコンが切り替わる。レイヤーの表示/非表示などに使う。

L.easyButton({
  states: [
    {
      stateName: 'show',
      icon:  'fa-solid fa-eye',
      title: 'レイヤーを非表示',
      onClick(btn, map) { overlay.remove(); btn.state('hide'); }
    },
    {
      stateName: 'hide',
      icon:  'fa-solid fa-eye-slash',
      title: 'レイヤーを表示',
      onClick(btn, map) { overlay.addTo(map); btn.state('show'); }
    }
  ]
}).addTo(map);

複数ボタンのグループ化（easyBar）

L.easyBar でまとめると、標準のズームコントロールと同じ外観のボタン群になる。

L.easyBar([
  L.easyButton('fa-solid fa-magnifying-glass-plus',  zoomIn),
  L.easyButton('fa-solid fa-magnifying-glass-minus', zoomOut),
  L.easyButton('fa-solid fa-house',                  goHome),
]).addTo(map);

3ライブラリの役割まとめ

ライブラリ 役割 Font Awesome との接点
Font Awesome アイコン素材の提供 —（提供側）
Leaflet 地図の描画・操作 L.divIcon の html にアイコンを埋め込む
easy-button.js 地図コントロールにボタンを追加 第1引数にクラス名を渡すだけでアイコンボタン化

よくあるトラブル

症状 原因と対処
□（豆腐）で表示される クラス名の誤り。fa-solid / fa-regular / fa-brands のどれかを必ず付ける
easyButton のアイコンが出ない Font Awesome の CSS が easyButton の JS より後に読み込まれている。順序を入れ替える
divIcon に白背景が残る className: '' を付け忘れている
v4 のクラス名（fas / fab）が効かない v6 では fa-solid / fa-brands に変更された

良く使いそうなアイコン一覧も作成した。検索もできる。アイコンサイズや色も変更できる。
