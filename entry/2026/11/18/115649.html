Excel）全セル内の特定の文字列のみ色を付ける方法。マクロ作成し、クイックアクセスツールバーに登録。

2026-11-18 · コンピュータ

Excelで、全セル内の特定の一部の文字列のみ色を付ける機能は標準にはない。VBA（マクロ）を作成し、クイックアクセスツールバーに登録する方法を使う。

【 VBA（マクロ）作成 】

※ VBAマクロをブックに保存して使う場合は、Excelの拡張子を、「xlsx」から「xlsm」にしておく必要がある（？）。

キーボードの Alt + F11 キーを押して、VBAエディタ（Visual Basic Editor）を起動。

メニューバーの [挿入] ＞ [標準モジュール]をクリック。

開いた白いコード入力ウィンドウに、以下のコードをそのまま貼り付ける。以下のマクロは対象セルを選択する必要はない。すべてのセル（使用されている範囲）が自動的に対象になる。

画面右上にある × ボタンを押して、VBAエディタ（Visual Basic Editor）を閉じる。（コードは自動的に保存される。）

Sub HighlightSpecificTextPrompt()
    Dim ws As Worksheet
    Dim findText As String
    Dim targetCell As Range
    Dim cellText As String
    Dim pos As Long
    Dim colorChoice As Variant
    Dim fontColor As Long
    Dim isBold As Boolean
    Dim colorName As String

    ' --- 1. 検索する文字列を入力 ---
    findText = Application.InputBox( _
        Prompt:="検索してハイライトする文字列を入力してください:", _
        Title:="文字列の検索と書式設定", _
        Type:=2)

    If findText = "False" Or findText = "" Then Exit Sub

    ' --- 2. 色の選択ポップアップ ---
    colorChoice = Application.InputBox( _
        Prompt:="変更する色の番号を入力してください:" & vbCrLf & vbCrLf & _
                "  1 : 赤" & vbCrLf & _
                "  2 : 青" & vbCrLf & _
                "  3 : 緑" & vbCrLf & _
                "  4 : 黒(太字なし・リセット用)", _
        Title:="色の選択", _
        Default:=1, _
        Type:=1) ' Type 1 = 数値入力

    ' キャンセル時は False が返る
    If VarType(colorChoice) = vbBoolean Then Exit Sub

    Select Case CLng(colorChoice)
        Case 1
            fontColor = RGB(255, 0, 0): isBold = True: colorName = "赤"
        Case 2
            fontColor = RGB(0, 0, 255): isBold = True: colorName = "青"
        Case 3
            fontColor = RGB(0, 176, 80): isBold = True: colorName = "緑"
        Case 4
            fontColor = RGB(0, 0, 0): isBold = False: colorName = "黒(リセット)"
        Case Else
            MsgBox "1〜4の数字を入力してください。", vbExclamation
            Exit Sub
    End Select

    ' --- 3. 検索して書式を適用 ---
    Set ws = ActiveSheet
    Application.ScreenUpdating = False

    For Each targetCell In ws.UsedRange
        If Not IsEmpty(targetCell.Value) Then
            If Not IsError(targetCell.Value) Then
                cellText = CStr(targetCell.Value)

                pos = InStr(1, cellText, findText, vbTextCompare)
                Do While pos > 0
                    With targetCell.Characters(pos, Len(findText)).Font
                        .Color = fontColor
                        .Bold = isBold
                    End With
                    pos = InStr(pos + 1, cellText, findText, vbTextCompare)
                Loop
            End If
        End If
    Next targetCell

    Application.ScreenUpdating = True
    MsgBox "「" & findText & "」を【" & colorName & "】に変更しました。", vbInformation
End Sub

クイックアクセスツールバーに登録する。 Excelの上部にある「クイックアクセスツールバー」にこのマクロを登録しておく。そうすれば、ボタンクリックでダイアログを呼び出せるようになり、VBAエディタを開く必要がなくなる。

【 クイックアクセスツールバー 登録手順 】
  1. Excelのオプション画面を開く
    • Excel画面の上部メニューにある [ファイル] タブをクリック。
    • 左側の一番下にある [オプション] をクリック。
  2. 「クイックアクセスツールバー」の設定画面を表示する
    • 開いたウィンドウの左側メニューから [クイックアクセスツールバー] を選択。
  3. マクロを選択して追加する

    • 画面中央にある「コマンドの選択」のプルダウンをクリックし、[マクロ] に変更。
    • リストの中に先ほど作成したマクロ HighlightSpecificTextPrompt が表示されるので、クリックして選択。
    • 中央にある [追加 >>] ボタンをクリックすると、右側の「クイックアクセスツールバーのユーザー設定」の一覧にマクロが移動。
  4. アイコンや名前を変更する（任意）
    • 右側のリストに追加したマクロを選択した状態で、右下の [変更...] ボタンを押す。
    • 好みのアイコンを選び、「表示名」をわかりやすい名前（例：「選択文字色付け」など）に書き換えて [OK] を押す。

  5. 設定を保存する
    • ウィンドウ右下の [OK] ボタンをクリックして設定画面を閉じる。
【 クイックアクセスツールバー 使い方 】
  • Excel画面の左上（または上部）にあるクイックアクセスツールバーに、先ほど設定したアイコンが表示される。
  • どのシートを開いているときでも、そのボタンを 1回クリック すれば、検索文字を入力するポップアップが即座に起動する。

【 結果サンプル 】

【 Excel ファイルを別フォルダーにコピーしてマクロを使用するとエラーになる 】

※ 作成したExcelを別フォルダーに移動して使うとエラーが出る。

これを解決するためには、個人用マクロブック（PERSONAL.XLSB）を作成する必要があるらしいが、それをしても、「クイックアクセスツールバーのボタン（アイコン）」はパソコン本体（レジストリや設定ファイル）に保存されているため、別PCには引き継がれないらしい。
