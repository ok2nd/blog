このWordPressの外観テーマを「Semplicemente」に変更。

【はてなブログ「晴歩雨描」のテーマ：Minimalism】

一旦はテーマを「Twenty Sixteen」にしたが、3カラム形式だったので、2カラム形式を探した。

【WordPressテーマ：Twenty Sixteen】

【WordPressテーマ：Semplicemente】

シンプルな2カラム形式のテーマ。

「Semplicemente」が良いのは、トップページが記事一覧形式になること。アイキャッチ画像はこの状態では入らないが、後で画像表示できるようにする。

テーマ「Semplicemente」は、一部カスタマイズをした。

  • ［外観］＞［カスタマイズ］＞［ウィジェット］＞［サイドバー］

で、「最近の投稿」と「最近のコメント」を削除した。

※ 「サンプルページ」が邪魔なので、削除。

  • ［固定ページ］

で、「サンプルページ」をゴミ箱へ移動する。

※ 記事一覧の表示から、下部の「編集」と「続きを読む」を表示しないようにする。

　↓↓↓

設定は以下。

\wp-content\themes\semplicemente\style.css

で、以下のようにする。

footer.entry-footer {
	display: none;
	padding: 1.5em;
	border-top: 1px solid rgba(0,0,0,.05);
}
.entry-content {
	margin: 1.5em 0 1.5em 0;
	padding: 0 1.5em;
}
