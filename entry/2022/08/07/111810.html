WordPress用のデータベースを切り替えてみる。

  • http://localhost/xampp/

で、「phpMyAdmin」を開いて、切り替え用データベースを作成する。

「wp-config.php」ファイル

\xampp\htdocs\wordpress\wp-config.php

の「DB_NAME」を変更する。

/** WordPress のためのデータベース名 */
define('DB_NAME', 'wp_test');

/** MySQL データベースのユーザー名 */
define('DB_USER', 'root');

/** MySQL データベースのパスワード */
define('DB_PASSWORD', '*****');
  • http://localhost/wordpress/
