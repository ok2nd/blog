Windows）「Python（Ver.3.11.5）」インストール。

2023-09-08 · コンピュータ

Windows版Pythonのインストール手順の備忘録。

■ Pythonダウンロード

Download PythonThe official home of the Python Programming LanguagePython.org

現時点の最新、Ver.3.11.5。

■ Python インストール

「python-3.11.5-amd64.exe」を実行。

「Add Python.exe to PATH」にチェックを入れて、「Customize installation」。

「install location」でPython用データのディレクトリを変更して「Install」。

■ Python インストールチェック

「コマンドプロンプト」を開いて、次のコマンドを入力してPythonのバージョンを確認。

python --version
