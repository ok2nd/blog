● 画像生成AIを使うには、以下の3つが必要。

  • UI（操作するための画面＋VRAM効率化など）
  • エンジン（実際に画像を作る仕組み）
  • モデル（AIの知識・作風）

● 画像生成エンジンは、Stable Diffusionを使う。現時点での主なUIとモデルの選択肢は以下。

Stable Diffusion（エンジン）
├─ UI
│   ├─ Fooocus
│   ├─ ComfyUI
│   ├─ AUTOMATIC1111（本家）
│   └─ Forge（A1111改良版）
└─ モデル
    ├─ SD1.5
    ├─ SDXL
    └─ FLUX.1

Fooocusは、自動的にSDXL系モデルを使う。

期待通りの画質を得られなかったのは、SDXL系モデルが要因と思われる。モデルとしては、「FLUX.1」の方が優れていそう。

ということで、モデル「FLUX.1 [dev] の GGUF版」を試してみた。

※ なぜ「FLUX.1 [dev] の GGUF版」なのか？

使うPCのスペックは以下。画像生成AIをローカルで行うPCとしては最低限レベル。

CPU インテル Core i5-14500T (14コア(6P+8E)/1.7GHz)
GPU NVIDIA GeForce RTX 3050 LP 6GB
メモリー 32GB
ストレージ 1TB M.2 SSD PCI Express x4対応（Gen4対応）
OS Windows 11 Pro 64bit

  • VRAM 6GBの壁: 通常のFLUXは動かないが、GGUF版（量子化モデル）なら、32GBのメインメモリを活用して6GBのGPUでも動作する。

  • 画質: FLUX.1 [dev] は [schnell] よりもディテールが深く、1200x900px程度の高解像度でも破綻しにくい。

以下の組み合わせで、使ってみる。

  • AIツール管理：Stability Matrix：複数のUIを切り替えて使える
  • UI：Forge（Stable Diffusion WebUI Forge）：低スペックPCでもFLUXを動かすための最適化が世界で最も進んでいるソフトの一つ
  • モデル：FLUX.1 [dev]
  • エンジン：Stable Diffusion

１．ツール（管理ソフト）＋UIの導入

複数のAIツールを簡単に管理できる「Stability Matrix」を使う。

  • ダウンロード: https://github.com/LykosAI/StabilityMatrix/releases

    • StabilityMatrix-win-x64.zip をダウンロードし、展開する。自分の場合、「C:\MyProgram\Stability Matrix」に展開。

    • 中に入っている「StabilityMatrix.exe」が、そのまま実行ファイル。

  • 「StabilityMatrix.exe」のショートカットをデスクトップに置き、実行する。（Portableモードで良い）

  • UIの選択で、Stable Diffusion WebUI Forge (By lllyasviel)を選択。

  • 推奨Modelの画面が出るが、ダウンロード不要。

  • 以下の画面が出れば、インストール完了。

２．モデルと補助ファイルを配置する

以下の4つのファイルをダウンロードし、それぞれのフォルダに入れる。

  • メインモデル「FLUX.1 [dev]」：flux1-dev-Q4_K_S.gguf 

    • https://huggingface.co/city96/FLUX.1-dev-gguf/tree/main

    • 保存場所: Data/Models/Stable-diffusion

  • VAE（Variational AutoEncoder）：「AIが理解できるデータ」と「人が見える画像」を変換する通訳：ae.safetensors

    • https://huggingface.co/lovis93/testllm/blob/ed9cf1af7465cebca4649157f118e331cf2a084f/ae.safetensors

    • 保存場所: Data/Models/VAE

  • CLIP（Contrastive Language–Image Pretraining）：文章の意味を画像生成AIに正しく伝える翻訳機：clip_l.safetensors

    • https://huggingface.co/comfyanonymous/flux_text_encoders/tree/main

    • 保存場所: Data/Models/TextEncoder（フォルダが無ければ作成する）

  • T5-XXL：プロンプト理解を劇的に強化する“巨大版CLIP”：t5xxl_fp16.safetensors

    • https://huggingface.co/comfyanonymous/flux_text_encoders/tree/main

    • 保存場所: Data/Models/TextEncoder（フォルダが無ければ作成する）

３．Forgeの設定

「StabilityMatrix.exe」を実行する。

「Launch」ボタンを押す。

ブラウザで、以下の画面が出る。

ブラウザ画面で以下の設定をする。

  • Checkpoint: 上部で flux1-dev-Q4_K_S.ggufを選択。

  • UI設定: 画面上部のタブを [flux] モードに切り替え。

  • VAE / Text Encoder: 必ず 3つのファイル（t5xxl, clip_l, ae）をセットする。

  • GPU Weight: デフォルトの 5119 ではエラーが出やすいため、「VRAM 6GBの場合は 3500 〜 4000 程度に下げる。

  • Sampling Steps: 20 以上（写真画質なら30推奨）。

  • Schedule type: Simple または Beta。

  • Distilled CFG Scale: 3.5（FLUXの標準値）。

  • Resolution: Width 800 / Height 600。サイズは任意だが、大きいと時間がかかる。

※ 補足：設定状態を保存する方法

  1. UI設定: 画面上部のタブを [all] モードに切り替える。（ [all] にしないと、Widht/Heightなどデフォルトになってしまう。）
  2. 「Settings」タブを開く。
  3. 左下の「Defaults」をクリック。
  4. 「View changes」ボタンを押す。
  5. 「Apply」ボタンを押す。
  6. 「Apply setings」ボタンを押す。
  7. 「Reload UI」ボタンを押す。
  8. フロッピーディスクアイコンを押す。

４．「Generate」ボタンを押す。

「Generate」ボタンを押すと生成が始まる。PCの処理能力によっては、かなりの時間がかかる。「Generate」を押しても数分間フリーズしたように見えるが、黒い画面（コンソール）で％が進んでいれば正常。
