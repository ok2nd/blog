● 使うPCのスペックは以下。画像生成AIをローカルで行うPCとしては最低限レベル。

CPU インテル Core i5-14500T (14コア(6P+8E)/1.7GHz)
GPU NVIDIA GeForce RTX 3050 LP 6GB
メモリー 32GB
ストレージ 1TB M.2 SSD PCI Express x4対応（Gen4対応）
OS Windows 11 Pro 64bit

● 画像生成AIを使うには、以下の3つが必要。

  • UI（操作するための画面＋VRAM効率化など）
  • エンジン（実際に画像を作る仕組み）
  • モデル（AIの知識・作風）

最近、新しいモデルがいくつかリリースされている。

モデル「FLUX.2 [klein]」の GGUF版」を使ってみたが、Stability Matrix＋Forgeの環境では、RuntimeErrorで使えなかった。

そこで、「写真画質」に特化した「FLUX FP8版」を使ってみた。

※「FP8」はデータの精度（8ビット浮動小数点数）を指しており、元の巨大なモデル（約23GB以上）を画質を落としすぎずに半分以下のサイズ（約12GB弱）に軽量化したモデルであることを意味する。

特徴 FP8版 (.safetensors) GGUF版 (.gguf)
通称 FP8版 GGUF版（量子化版）
VRAM消費 6GB～8GBでギリギリ 4GB～6GBでも余裕
画質 非常に良い（オリジナルに近い） 設定（Q4/Q5等）により変わるが良好
互換性 多くのUIで標準対応 ForgeやComfyUIの特定版で対応
  • ツール管理：Stability Matrix
  • UI：Forge（Stable Diffusion WebUI Forge）
  • エンジン：Stable Diffusion
  • モデル：FLUX FP8版（GGUFではない）
■ FLUX FP8版のダウンロード

入手先：https://huggingface.co/Kijai/flux-fp8/tree/main

  • ファイル：flux1-dev-fp8.safetensors
    画質と速度のバランスが完璧。VRAM 6GBの環境で最も「サクサク」動く可能性が高いサイズ。
  • 保存場所：Data/Models/Stable-diffusion
■ テキストエンコーダーのダウンロード

入手先：https://huggingface.co/chatpig/encoder/blob/main/t5xxl-encoder-q4_k_m.gguf

  • ファイル：t5xxl-encoder-q4_k_m.gguf
  • 保存場所：Data/Models/TextEncoder
■ 使い方

※「FLUX.1 [dev] GGUF」をすでに使っている前提で、

Stability Matrix＋Stable Diffusion WebUI Forge の画面で、

Checkpoint

  • sd\flux1-dev-fp8.safetensors を選択。

VAE / Text Encoder

  • t5xxl_fp16.safetensors のチェックを外し、
  • t5xxl-encoder-q4_k_m.gguf をチェックする。

GPU Weights

  • 4500～5000 MB

■ 結果サンプル

900x600ピクセルで3分程度、1200x800ピクセルで4分程度で、生成できた。画質は、「FLUX.1 [dev] の GGUF版」に負けないレベル。
