■ ステップ１：毛筆フォント「英椎行書」にする

この文章を入れた縦書きHTMLページのフォントを、無料の毛筆フォント「英椎行書（えいしいぎょうしょ）」にしてみた。

お知らせwww.ac-font.com

フォントファイルの指定方法は以下。CSSで指定する。

<style>
@font-face {
	font-family: "Acgyosyo"; /* フォントの名前（任意） */
	src: url("fonts/acgyosyo.ttf") format("truetype"); /* フォントファイルのパス */
}
html {
	font-family: "Acgyosyo",serif,sans-serif;
}
</style>
