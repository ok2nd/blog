Gemini）Python）「ファイル拡張子別フォルダー移動」Windowsアプリ作成。

2025-08-12 · 写真・カメラ ＜AI＞ コンピュータ

Pythonで「ファイル拡張子別フォルダー移動」Windowsアプリを作成。

生成AI「Gemini」「Claude」「ChatGPT GPT-5」で、以下のプロンプトで作成してみた。

【生成AI プロンプト】

Windows環境のPythonでアプリを作って。

  • Windowsフォルダ内のファイルを拡張子別に、拡張子名フォルダーに分類する。
  • 拡張子は、大文字小文字は区別せず、フォルダー名は、大文字にする。
  • 拡張子のJPGとJPEGは同じものとして扱う。フォルダー名は、JPGとする。
  • 処理対象フォルダーは、アプリのGUIで指定できるようにする。
  • 処理対象フォルダー選択用のフォルダー入力欄は、Windowsフォルダー等からコピー&ペーストできる。
  • 処理対象フォルダー選択ボタンを押したら、その時点のフォルダー入力欄のパスを開く。
  • 実行状況のログも表示して。

-------------------------

どの生成AIも、基本機能は一発で実現できた。フォルダー選択の動作とシンプルさで、「Gemini」版を採用。

【Pythonプログラム】

作成されたプログラムを、「拡張子別フォルダー移動.pyw」（名前は任意）という名前にして、デスクトップに置いておき、ダブルクリックで実行する。

【Pythonプログラムコード】
import tkinter as tk
from tkinter import filedialog, messagebox
import os
import shutil

class FileOrganizerApp:
    def __init__(self, root):
        self.root = root
        self.root.title("ファイル整理アプリ")
        self.root.geometry("600x400")

        # UI要素の配置
        self.create_widgets()

    def create_widgets(self):
        # フォルダーパス入力欄とボタン
        frame_path = tk.Frame(self.root, padx=10, pady=10)
        frame_path.pack(fill=tk.X)

        label_path = tk.Label(frame_path, text="対象フォルダーパス:")
        label_path.pack(side=tk.LEFT)

        self.entry_path = tk.Entry(frame_path, width=50)
        self.entry_path.pack(side=tk.LEFT, expand=True, fill=tk.X, padx=5)

        btn_browse = tk.Button(frame_path, text="フォルダー選択", command=self.browse_folder)
        btn_browse.pack(side=tk.LEFT)

        # 実行ボタン
        btn_run = tk.Button(self.root, text="実行", command=self.run_organizer, font=("", 12), bg="#4CAF50", fg="white")
        btn_run.pack(pady=10)

        # ログ表示エリア
        self.log_text = tk.Text(self.root, height=15, state="disabled", bg="#333", fg="#FFF")
        self.log_text.pack(fill=tk.BOTH, expand=True, padx=10, pady=5)

    def log_message(self, message):
        """ログをテキストボックスに追記する"""
        self.log_text.config(state="normal")
        self.log_text.insert(tk.END, message + "\n")
        self.log_text.see(tk.END)  # 最新の行を表示
        self.log_text.config(state="disabled")
        self.root.update()

    def browse_folder(self):
        """フォルダー選択ダイアログを開く"""
        current_path = self.entry_path.get()
        if os.path.exists(current_path):
            initial_dir = current_path
        else:
            initial_dir = os.path.expanduser("~")
        
        folder_selected = filedialog.askdirectory(initialdir=initial_dir)
        if folder_selected:
            self.entry_path.delete(0, tk.END)
            self.entry_path.insert(0, folder_selected)

    def run_organizer(self):
        """ファイル整理処理を実行する"""
        target_path = self.entry_path.get()
        if not os.path.isdir(target_path):
            messagebox.showerror("エラー", "指定されたパスは存在しないか、フォルダーではありません。")
            return

        self.log_text.config(state="normal")
        self.log_text.delete(1.0, tk.END)
        self.log_text.config(state="disabled")
        self.log_message(f"--- 整理を開始します: {target_path} ---")

        try:
            for filename in os.listdir(target_path):
                file_path = os.path.join(target_path, filename)
                
                # ファイルのみを対象とする
                if os.path.isfile(file_path):
                    _, ext = os.path.splitext(filename)
                    
                    if not ext:
                        continue # 拡張子がないファイルはスキップ
                    
                    # 拡張子を小文字に変換
                    ext_lower = ext.lstrip('.').lower()
                    
                    # JPGとJPEGを統合
                    if ext_lower in ["jpg", "jpeg"]:
                        folder_name = "JPG"
                    else:
                        folder_name = ext_lower.upper()

                    destination_folder = os.path.join(target_path, folder_name)
                    
                    # 存在しない場合はフォルダーを作成
                    if not os.path.exists(destination_folder):
                        os.makedirs(destination_folder)
                        self.log_message(f"新しいフォルダーを作成しました: {folder_name}")
                    
                    destination_path = os.path.join(destination_folder, filename)
                    
                    # ファイルを移動
                    shutil.move(file_path, destination_path)
                    self.log_message(f"ファイル '{filename}' を '{folder_name}' に移動しました。")

            self.log_message("\n--- 整理が完了しました！?? ---")

        except Exception as e:
            self.log_message(f"エラーが発生しました: {e}")
            messagebox.showerror("エラー", f"処理中にエラーが発生しました: {e}")

if __name__ == "__main__":
    root = tk.Tk()
    app = FileOrganizerApp(root)
    root.mainloop()
