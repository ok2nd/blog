今日、自分が作成したWebシステム「MyHome Portal」が立ち上がらなくなった。

MyHome Portal個人または家族で使える自宅用のWebポータルシステム「MyHome Portal」をオープンソース/フリーソフトとして公開しています。ok2nd.github.io

XAMPPコントロールパネルを見るとエラーが出ている。原因を探してみたが、よく分からない。

仕方なく、XAMPPを再インストール。

通常のインストールの手順は以下。※ 今回は再インストールなので、手順が少し違う。

MyHome Portal インストール手順MyHome Portalok2nd.github.io

【実際に行った手順】

■ バックアップ
  • 現在の最新のデータをバックアップする。以下の2つのディレクトリ。
D:\xampp\htdocs
D:\xampp\mysql\data
■ 現在入っているXAMPPを一旦アンインストール
  • アンインストールが始まるまで時間がかかる。始まってからも時間がかかる。

■ XAMPPバージョン
  • XAMPP 1.8.3
    「xampp-win32-1.8.3-5-VC11-installer.exe」を使用。
    ※「XAMPP 1.8.3」インストールインストーラー版は、Windows11の新しいバージョンでは、Windows Defender（SmartScreen）にブロックされてインストールできない場合がある。その場合は、ZIP版「xampp-win32-1.8.3-5-VC11.zip」を使用。

    https://sourceforge.net/projects/xampp/files/XAMPP%20Windows/1.8.3/

  • 参考：XAMPPバージョン
      XAMPP 1.8.3 XAMPP 5.x / 7.x / 8.x
    公開年 2013年頃 2015年以降～現在
    PHPバージョン PHP 5.5.x PHP 7.x～8.x（最新版では8.2～8.3）
    MySQL / MariaDB MySQL 5.6 系 MariaDB 10.x 系（MySQL互換）
    Apache Apache 2.4.x Apache 2.4.x（継続更新）
    phpMyAdmin 4.0 系 5.x 系（UI・セキュリティ向上）
    OpenSSL 1.0系 1.1～3.x（TLS1.3対応など）
    対応OS Windows XP～8 Windows 10～11 / macOS / Linux対応
    開発目的 PHP5系の古いサイト互換 PHP7～8向け最新開発環境
    ※ MySQLがOracle社に買収された後、オープンソースのコミュニティベースでの開発を継続するために、MySQLと高い互換性を持つMariaDBが採用されるようになった。
  • ※ Windows11で、「xampp-win32-1.8.3-5-VC11-installer.exe」を直接実行しようとすると、「このアプリは保護のためブロックされました」となり、起動できない。
    コマンドプロンプトを、管理者として実行した上で、コマンドプロンプトから、「xampp-win32-1.8.3-5-VC11-installer.exe」を実行。
■ XAMPPインストール
  • 不要なサービスは除く

■ XAMPPインストールディレクトリ
  • D:\xampp（Dドライブ）


■ XAMPPコントロールパネルを管理者で実行するように設定
  • 「xampp/xampp-control.exe」のプロパティを開いて、「管理者としてこのプログラムを実行する」にチェックを入れる。

■ XAMPPコントロールパネル
  • ApacheとMySQLをサービスとして実行するように設定する。

■ XAMPP動作確認
  • ブラウザで、「http://localhost/」と入れて初期画面を表示。
  • 表示されたページで「日本語」を選択。

■ XAMPP一旦停止
  • XAMPPコントロールパネルで、ApacheとMySQLをストップする。
■ PHPタイムゾーンを変更
  • 「D:\xampp\php\php.ini」修正
    date.timezone = Europe/Berlin
   ↓↓↓
date.timezone = Asia/Tokyo
■ バックアップデータを戻す
  • 運用中のシステムのバックアップがあるので、通常のセットアップは不要。
  • 以下の2つのバックアップデータを戻す
    D:\xampp\htdocs
D:\xampp\mysql\data
■ PC再起動
  • パソコンを再起動して、XAMPPおよび「MyHome Portal 」が正常に立ち上がるのを確認。
