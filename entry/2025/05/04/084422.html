Webページから<ol><ul>リストを含むテキストをクリップボードにコピーするブックマークレット「文字列コピー」。

2025-05-04 · コンピュータ ホームページ、Web作成 ＜AI＞

ブラウザに表示されている文字列をマウスで範囲選択して、クリップボードにコピーするブックマークレットを作成。ChatGPTで作成。

通常のコピーでは、<ol><ul>で囲まれたリストは数字や中点なしでコピーされる。

今回作成したブックマークレットでは、<ol><ul>で囲まれたリストは、数字や中点付きでコピーする。

見やすくするため、改行コードは2つずつ入れることにした。

≪ブックマークレット≫
javascript:(function(){
  function getSelectedHtml() {
    const sel = window.getSelection();
    if (!sel.rangeCount) return '';
    const container = document.createElement('div');
    for (let i = 0; i < sel.rangeCount; ++i) {
      container.appendChild(sel.getRangeAt(i).cloneContents());
    }
    return container;
  }

  function processNode(node, depth = 0, listType = null, listIndex = 1) {
    let text = '';
    for (let child of node.childNodes) {
      if (child.nodeType === Node.TEXT_NODE) {
        text += child.textContent;
      } else if (child.nodeType === Node.ELEMENT_NODE) {
        const tag = child.tagName.toLowerCase();

        if (['p', 'br', 'h1','h2','h3','h4','h5','h6'].includes(tag)) {
          text += processNode(child, depth, listType, listIndex) + '\n\n';
        } else if (tag === 'ul' || tag === 'ol') {
          const isOrdered = tag === 'ol';
          let liIndex = 1;
          for (let li of child.children) {
            if (li.tagName.toLowerCase() === 'li') {
              const prefix = isOrdered ? `${liIndex}. ` : '・';
              text += '  '.repeat(depth) + prefix + processNode(li, depth + 1, tag, liIndex) + '\n\n';
              liIndex++;
            }
          }
        } else {
          text += processNode(child, depth, listType, listIndex);
        }
      }
    }
    return text;
  }

  const selected = getSelectedHtml();
  const processed = processNode(selected).trim();

  navigator.clipboard.writeText(processed).then(() => {
    alert("選択範囲のテキストを整形してコピーしました！");
  }).catch(err => {
    alert("コピーに失敗しました: " + err);
  });
})();
■ ブックマークレットの登録方法
  1. ブラウザのブックマークバーに、ページを追加で新しいブックマークを作成。
  2. ブックマークに任意の名前（例：文字列コピー）を付ける。
  3. ブックマークのURL欄に、上のブックマークレットのコードを貼り付ける。
  4. ブックマークを保存する。

■ ブックマークレットの実行方法
  1. 目的のWebページを開いている状態で、コピーしたい文字列をマウスで範囲選択する。
  2. ブックマークレット（例： 文字列コピー）をクリックする。

範囲選択した文字列がクリップボードにコピーされる。
