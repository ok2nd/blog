JavaScriptで生成・展開した（動的に書き換えられた）HTMLの中身を確認するためのデバッグ用のコード。

2025-02-19 · ホームページ、Web作成

JavaScriptで生成・展開した（動的に書き換えられた）HTMLは、ブラウザで[Ctrl]+[u]キーでソース表示しても確認できない。

デバッグ用に、JavaScriptで生成・展開した（動的に書き換えられた）HTMLの中身をテキストファイルとしてダウンロードするJavaScript関数を作成した。

function downloadUpdatedHTML() {
	// 100ms 待機して最新のHTMLを取得（変更が反映されるのを待つ）
	setTimeout(() => {
		let htmlContent = document.documentElement.outerHTML;
		// Blobを作成
		let blob = new Blob([htmlContent], { type: 'text/plain' });
		// ダウンロード用のリンクを作成
		let a = document.createElement('a');
		a.href = URL.createObjectURL(blob);
		a.download = 'updated_page.html'; // ダウンロードするファイル名
		document.body.appendChild(a);
		// リンクをクリックしてダウンロード
		a.click();
		// 一時的な要素を削除
		document.body.removeChild(a);
	}, 100); // 100ms 待機してDOMの変更を確実に取得
}

この関数を、JavaScriptロジックの最後でコールする。

downloadUpdatedHTML();
