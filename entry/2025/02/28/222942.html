JavaScriptで生成・展開した（動的に書き換えられた）HTMLの中身をテキストファイルとしてダウンロード保存するブックマークレット作成。

JavaScriptで生成・展開した（動的に書き換えられた）HTMLは、ブラウザで[Ctrl]+[u]キーでソース表示しても確認できない。

以前に、JavaScriptで動的に書き換えられたHTMLの中身をテキストファイルとしてダウンロードするJavaScript関数を作成した。

今回、デバッグ用のJavaScript関数ではなく、ブックマークレットとして作成した。これなら、デバッグ用にHTMLを編集する必要がない。

≪ブックマークレット≫
javascript:(function(){
  let htmlContent = document.documentElement.outerHTML;
  let blob = new Blob([htmlContent], { type: 'text/plain' });
  let a = document.createElement('a');
  a.href = URL.createObjectURL(blob);
  a.download = 'updated_page.html';
  document.body.appendChild(a);
  a.click();
  document.body.removeChild(a);
})();
■ ブックマークレットの登録方法
  1. ブラウザのブックマークバーに、ページを追加で新しいブックマークを作成。
  2. ブックマークに任意の名前（例： HTML保存）を付ける。
  3. ブックマークのURL欄に、上のブックマークレットのコードを貼り付ける。
  4. ブックマークを保存する。

■ ブックマークレットの実行方法
  1. 任意のウェブページを開く。
  2. 作成したブックマークレット（例： HTML保存）をクリックする。
  3. ウェブページのHTMLファイル（updated_page.html）がダウンロードされる。
