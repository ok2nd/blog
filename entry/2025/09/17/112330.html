CSSレスポンシブ対応）スマホの機種によらず、画面横の文字数を同じにしたければ、font-sizeにvwを使う。

2025-09-17 · ホームページ、Web作成 スマホ・タブレット

スマホは、機種によって画面の横幅のサイズが違う。ブラウザのpixelサイズも違う。

＜ ブラウザの表示幅・ピクセル(pixel)チェック ＞

https://ok2nd.github.io/tool/html/pixel-check.html

フォントサイズの指定方法には以下のものがある。

  • px：ピクセル(pixel)絶対値
  • em：親要素のfont-sizeを1とした倍率
  • rem：文書のルート要素のfont-sizeを1とした倍率
  • %：親要素のfont-sizeを基準値
  • vh：ビューポートの高さの%
  • vw：ビューポートの横幅の%

スマホの機種によらず、画面横幅に入る文字数を統一したい場合、「vw」を使うのが一番確実。

%指定は親要素のフォントサイズを基準にするが、vwはビューポート（ブラウザの表示領域）の幅を基準にする点が違う。親要素に依存せず、デバイスの幅に合わせられる点が使いやすい。

【例】

例として、カレンダースケジュールをスマホ画面に表示したい場合、1日の予定項目を5文字表示して、横に1週間分並べたい場合などに、「vw」を使えば良い。

font-size: 2.4vw;

「font-size: 2.4vw」にすると、2.4×(1日5文字×7日文)=84となり、罫線やマージンなどを除いて、丁度よい。

PC用の画面にも、これを適用すると文字がかなり大きくなるので、@mediaを使うなどして、一定の横幅のデバイスのみに適用したい。

自分が所有しているスマホでは、横幅は360ピクセルから417ピクセルだった。

@media (max-width: 480px) {
	.schedule-entry	{
		font-size: 2.4vw;
		padding: 0.8vw;
		margin-top: 0; 
	}
}
